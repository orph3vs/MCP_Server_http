# 골든 질문 세트

이 문서는 법령 MCP 서버의 회귀 기준 질문을 정리한 것이다.

목적은 다음과 같다.

- 수정 후에도 반드시 유지되어야 하는 출력 계약을 고정한다.
- 특정 버그를 고쳤다가 다른 질문 품질을 떨어뜨리는 회귀를 빠르게 찾는다.
- `single_basis`, `framework_overview`, `privacy_categories`가 실제로 기대한 경로를 타는지 점검한다.

질문별로 최소한 아래를 같이 본다.

- 질문 원문
- 기대 모드
- 기대 법령군 / 핵심 조문
- 기대 핵심 문장
- 금지 오답 패턴

## 질문 목록

### 1. 주민등록번호 동의만으로 처리 가능 여부

- 질문: `주민등록번호 수집할 때 정보주체한테 동의받아서 처리하면 되지?`
- 기대 모드: `single_basis`
- 기대 법령 / 조문: `개인정보 보호법 제24조의2`
- 기대 핵심:
  - 주민등록번호는 정보주체의 동의만으로 처리할 수 없다고 설명할 것
  - 법령상 구체적 근거가 있는 경우 등 예외를 말할 것
- 금지 오답:
  - `개인정보 영향평가`
  - `개인정보 보호법 시행령 제35조`

### 2. 민감정보 처리 가능 여부

- 질문: `민감정보는 동의받으면 처리할 수 있나?`
- 기대 모드: `single_basis`
- 기대 법령 / 조문: `개인정보 보호법 제23조`
- 기대 핵심:
  - 민감정보 처리 제한을 별도로 설명할 것
- 금지 오답:
  - unrelated 시행령 운영조문

### 3. 고유식별정보 처리 가능 여부

- 질문: `고유식별정보는 동의만 있으면 처리 가능한가?`
- 기대 모드: `single_basis`
- 기대 법령 / 조문: `개인정보 보호법 제24조`
- 기대 핵심:
  - 주민등록번호 특례와 구분할 것
  - 별도 동의 또는 법령상 근거를 설명할 것
- 금지 오답:
  - 주민등록번호 특례만으로 답하는 것

### 4. 학교밖청소년지원센터 주민등록번호 수집

- 질문: `학교밖청소년지원센터는 주민등록번호 수집 가능 함?`
- 기대 모드: `single_basis`
- 기대 핵심:
  - 질문 기준 법령군을 먼저 검토할 것
  - 직접 근거가 없으면 보완 법령을 분리해 설명할 것
- 금지 오답:
  - 관련 법령을 질문 기준 법령처럼 단정하는 것

### 5. 노인일자리법 고유식별정보

- 질문: `노인일자리법에 근거해서 노인의 고유식별정보를 수집할 수 있는가?`
- 기대 모드: `single_basis`
- 기대 법령 / 조문: `노인 일자리 및 사회활동 지원에 관한 법률 시행령 제14조`
- 기대 핵심:
  - 질문 기준 법령군에서 직접 근거를 찾을 것
  - 주민등록번호 / 외국인등록번호 범위를 구분할 것
- 금지 오답:
  - 개보법 일반론만으로 끝나는 것

### 6. 아파트 관리업체와 주민 정보

- 질문: `아파트 관리를 어떤 특정 업체에서 맡아서 할 수 있나? 그리고 그 업체에서는 주민들의 정보를 수집할 수 있어?`
- 기대 모드: `single_basis`
- 기대 법령:
  - `공동주택관리법`
  - `개인정보 보호법 제15조`
  - `개인정보 보호법 제26조`
  - 필요시 `개인정보 보호법 제24조의2`
- 기대 핵심:
  - 위탁관리 가능 여부와 개인정보 처리 근거를 분리할 것
  - 일반 개인정보와 주민등록번호를 구분할 것
- 금지 오답:
  - `개인정보 보호법 시행령 제62조의2` 같은 generic 조문이 메인으로 뜨는 것

### 7. 동의 철회 방법과 제재

- 질문: `동의 철회 방법을 어렵게 하면 어떤 조항으로 처벌되나?`
- 기대 모드: `single_basis`
- 기대 카테고리:
  - `정보주체 권리`
  - `절차/방법`
  - `제재/책임`
- 기대 핵심:
  - 처리 일반이 아니라 권리 보장, 절차, 제재 관점으로 접근할 것
- 금지 오답:
  - `고유식별정보의 처리`류 조문

### 8. 문자/온라인 광고의 법적 근거

- 질문: `문자 광고나 온라인 광고에 관련된 법적 근거를 알려줘`
- 기대 모드: `framework_overview`
- 기대 축:
  - 광고성 정보 전송 규제
  - 광고 목적 개인정보 활용
  - 광고 내용/표시 규제
  - 필요시 통신판매/소비자 유인 규제
- 금지 오답:
  - 조문 하나로 전체를 설명하는 것
  - `개인정보 보호법 시행령 제30조`

### 9. 특정 조문 해석

- 질문: `개인정보 보호법 제24조의2가 무슨 뜻이야?`
- 기대 모드: `single_basis`
- 기대 핵심:
  - framework로 확장하지 말 것
  - 해당 조문 해석에 집중할 것

### 10. 문자 광고 수신거부 후 재전송

- 질문: `문자 광고 수신거부를 했는데 계속 오면 위반이야?`
- 기대 모드: `single_basis`
- 기대 법령 / 조문: `정보통신망 이용촉진 및 정보보호 등에 관한 법률 제50조`
- 기대 핵심:
  - 수신거부 후 재전송 금지와 제재 가능성을 설명할 것
- 금지 오답:
  - 개보법 일반론만으로 답하는 것

## 운영 원칙

- 새 버그를 고칠 때는 먼저 이 질문 세트를 다시 돌린다.
- 새 질문 유형이 두 번 이상 반복되면 골든 질문 세트에 추가한다.
- 새 기능을 넣더라도 기존 골든 질문의 기대 모드와 금지 오답은 유지한다.
